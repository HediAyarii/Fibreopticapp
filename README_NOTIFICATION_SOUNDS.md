# Sons de Notification WhatsApp

## Fichiers Audio Requis

Pour que les notifications sonores fonctionnent, vous devez ajouter les fichiers audio suivants dans le dossier `public/sounds/` :

### 1. Son pour les Réclamations
- **Fichier** : `public/sounds/reclamation.mp3`
- **Description** : Son d'alerte pour les nouvelles réclamations
- **Durée recommandée** : 2-3 secondes
- **Format** : MP3, WAV ou OGG

### 2. Son pour les Pénalités  
- **Fichier** : `public/sounds/penalite.mp3`
- **Description** : Son d'alerte pour les nouvelles pénalités
- **Durée recommandée** : 2-3 secondes
- **Format** : MP3, WAV ou OGG

## Sources de Sons Gratuits

Vous pouvez télécharger des sons gratuits depuis :

1. **Freesound.org** - Sons libres de droits
2. **Zapsplat.com** - Bibliothèque de sons gratuits
3. **BBC Sound Effects** - Sons de la BBC
4. **YouTube Audio Library** - Sons libres de droits

## Mots-clés de Recherche

Pour trouver des sons appropriés, recherchez :
- "notification sound"
- "alert sound"
- "warning beep"
- "notification bell"
- "alert tone"

## Configuration Alternative

Si vous ne souhaitez pas ajouter de fichiers audio, le système fonctionnera sans sons. Les notifications visuelles et du navigateur fonctionneront toujours.

## Test des Sons

Une fois les fichiers ajoutés, vous pouvez tester les sons en :
1. Ouvrant le dashboard technicien
2. Créant une réclamation ou pénalité depuis l'espace admin
3. Vérifiant que le son se joue automatiquement
